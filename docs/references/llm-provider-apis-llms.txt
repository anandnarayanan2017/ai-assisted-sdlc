# LLM provider wire formats — condensed reference (harness/src/llm.ts)

## Anthropic Messages API
POST https://api.anthropic.com/v1/messages
headers: x-api-key: <key>, anthropic-version: 2023-06-01, content-type: application/json
body: { model, max_tokens (required), system: "<string>", messages: [{ role: "user", content: "<text>" }], temperature? }
reply: { content: [{ type: "text", text }], stop_reason: "end_turn" | "max_tokens" | ..., usage: { input_tokens, output_tokens } }
errors: 401 bad key, 429 rate limit, 529/5xx overloaded -> retry with backoff.

## OpenAI Chat Completions (and every "OpenAI-compatible" server)
POST <baseUrl>/chat/completions
headers: authorization: Bearer <key>, content-type: application/json
body: { model, messages: [{ role: "system", content }, { role: "user", content }], max_tokens | max_completion_tokens, temperature? }
reply: { choices: [{ message: { content }, finish_reason: "stop" | "length" | ... }], usage: { prompt_tokens, completion_tokens } }

Base URLs (check each vendor's docs for current values and model ids):
- OpenAI           https://api.openai.com/v1            (reasoning models: max_completion_tokens, default temperature only)
- Google Gemini    https://generativelanguage.googleapis.com/v1beta/openai
- Mistral          https://api.mistral.ai/v1
- DeepSeek         https://api.deepseek.com/v1
- OpenRouter       https://openrouter.ai/api/v1          (many vendors behind one key)
- Ollama (local)   http://localhost:11434/v1            (no key; from Docker: http://host.docker.internal:11434/v1)
- vLLM / LM Studio http://<host>:<port>/v1

## Benchmark-relevant conventions
- pass@1 runs: temperature 0 where supported. pass@k (k>1): temperature 0.8, n >= k samples per task.
- Count tokens from the provider's usage block; never estimate from characters for cost.
